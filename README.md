# BrainBox

BrainBox est une application de gestion de connaissances permettant d'ajouter, consulter, modifier et supprimer des connaissances.  
L'application intègre également un assistant IA basé sur Ollama afin de répondre aux questions des utilisateurs uniquement à partir des connaissances enregistrées.

## Architecture du projet

Le projet est composé de trois parties :

- **Frontend** : Angular
- **Backend** : Node.js / Express
- **Base de données** : MongoDB Atlas
- **Assistant IA** : Ollama avec un modèle local (qwen3:8b)


## les prérequis
Avant d'installer BrainBox, il faut s'assurer d'avoir installer Docker.

Pour installer docker https://docs.docker.com/get-started/
Créer un compte ou relier son github.

Pour vérifier l'installation :

```bash
docker --version
docker compose version
```
